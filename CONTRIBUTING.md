# Contributing

Thanks for your interest in contributing! Please open an issue before making significant changes, keep pull requests focused, and include tests or screenshots when relevant.

## Pull requests

1. Fork the repository and create a descriptive branch.
2. Make focused changes and update documentation as needed.
3. Run the project checks locally.
4. Open a pull request describing the change, testing performed, and any follow-up work.

Please follow the existing code style and be respectful in all discussions.
